Do I have any critisizm towards the technology I used? A lot.

LLM
Although Gemini 3 Pro gave me a significant boost, it is not a model that is ready for such a scientific research. It's fine-tuned to please the develop and find the shortest way to possible to fix a bug. This is not the behaviour I want in this project. This is not my business project. I don't want to have revenue tomorrow. I want a solid fundamental research with high-confidence results.
Another problem is context management. Gemini 3 Pro claims to have 1m window. But when I reach ~300k, the intelligence levels drop significantly.
This is relevant to other models. This lead to an interesting paradox: sometimes smaller window is better! Because Cursor chooses to summarize the context and proceed with it. Instead of growing the context in an uncontrollable manner. It reduces the probability of running in circles.
Lessons:
- we need more context for big scientific projects. Not just numbers, but better context management.
- we need a fine-tuned LLM that treats long conversations like normal ones. Not like "I need to find a shortcut asap to please the user".
