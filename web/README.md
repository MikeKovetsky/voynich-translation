# Voynich Manuscript Viewer

A React-based web viewer for the Voynich Manuscript translation project.

## Setup

1. Install dependencies:
   ```bash
   cd web
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

## Data Update Runbook

To update the statistics and translations displayed in the web interface with the latest research results, follow these steps:

### 1. Prerequisites
Ensure you have the latest research results:
- A generated full translation file (e.g., `results/voynich_full_translation_v8.md`).
- The latest dictionary file (e.g., `results/dictionary/dictionary_v12.json`).

### 2. Run the Update Script
From the **root of the repository** (not the `/web` folder), run:

```bash
python3 research/finalize_web_data.py
```

This script automates the entire process:
1.  **Copies the Dictionary**: Moves the latest JSON dictionary to `web/src/data/dictionary.json`.
2.  **Splits Translations**: Calls `research/split_translations.py` to chop the massive Markdown translation file into individual page files in `translated/`.
3.  **Updates Web Data**: Aggregates these page files into `web/src/data/translations.json` and updates the page index.

### 3. Verify Updates
1.  Start the web server (`npm run dev` in `/web`).
2.  Navigate to `http://localhost:5173/stats`.
3.  Check if the "North Star Metric" (Dictionary Completeness) and "Coverage" percentages have updated.

### 4. Troubleshooting
*   **Missing Files:** If the script fails, check `research/finalize_web_data.py` lines 12-15 to ensure it points to the correct *source* dictionary version (e.g., `dictionary_v12.json`).
*   **Old Translations:** If translations seem stale, manually delete the `translated/` folder and re-run the script.

## Data Structure

- **Images**: The manuscript images are served from `public/manuscript/` (symlinked to the project root `images/` folder).
- **Pages**: The list of page filenames is in `src/data/pages.json`.
- **Translations**: `src/data/translations.json` (Generated by the script).
- **Dictionary**: `src/data/dictionary.json` (Generated by the script).
