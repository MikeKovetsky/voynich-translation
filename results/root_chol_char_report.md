# Root Analysis: `chol` and `char`

## Goal
Determine the meaning of the high-frequency roots `chol` and `char` using morphological analysis and visual correlation on herbal pages.

## Task 1: Morphology Check

### `chol` Variations
The root `chol` is highly productive and takes several prefixes, including the biological `qok-`.
- **Base**: `chol` (374 occurrences)
- **Prefixes**:
  - `qok-` (17): `qokchol` ("with the chol" / "in the chol")
  - `d-` (18): `dchol` ("of/from chol")
  - `t-` (12): `tchol`
  - `y-` (11): `ychol`
  - `o-` (5): `ochol`

### `char` Variations
The root `char` is less frequent but also takes the `qok-` prefix.
- **Base**: `char` (68 occurrences)
- **Prefixes**:
  - `qok-` (1): `qokchar` ("with the char")
  - `d-` (3): `dchar`
  - `t-` (4): `tchar`

## Task 2: Visual Correlation

### `chol` vs Leaves
Analysis of pages classified by leaf size shows a strong correlation with **Big Leaves**.
- **Big Leaves** (e.g., f5r, f2v, f25v): **46.41 per 1k** (n=22)
- **Small Leaves** (e.g., f4r, f17r): **24.84 per 1k** (n=8)
- **Ratio**: **1.87x** more frequent on Big Leaf pages.

### `char` vs Flowers
- **Flowers**: **6.79 per 1k** (n=4)
- **No Flowers**: **4.83 per 1k** (n=1)
- **Ratio**: **1.41x** (Weak correlation)

### `char` vs Roots
- **Roots**: **6.76 per 1k** (n=5)
- **No Roots** (f5r): **0.00 per 1k** (n=0)
- **Correlation**: Suggestive of a link to Roots, but sample size for "No Roots" is small.

## Task 3: Hypothesis Generation

### Hypothesis for `chol`: **LEAF** (or Foliage)
- **Evidence**:
  - Strong correlation with Big Leaves (where leaves are a prominent feature).
  - Takes `qok-` ("With the leaves" - common in herbal recipes).
  - High frequency fits "Leaf" which is a primary component of the herbal section.
- **Hebrew Connection**:
  - **Aleh** (עלה) = Leaf. EVA `al` exists, but `chol` might be a phonetic mapping or related to *Chol* (Sand/Soil) if it describes where it grows? 
  - Alternatively, `chol` might map to **Kol** (All/Whole) or **Chol** (Blue/Green - *Khol*). If *Khol* means "Green" (as in fresh/blue-green), it fits leaves.
  - *Chol* (Sand) is unlikely for a plant part, unless "Grows in sand".
  - **Proposed Meaning**: **Leaf / Foliage**.

### Hypothesis for `char`: **ROOT** (or Bulb)
- **Evidence**:
  - Appears on pages with Roots.
  - Absent on the "No Root" control page (f5r).
  - `qokchar` ("With the root") fits recipes.
- **Hebrew Connection**:
  - **Iqar** (עיקר) = Main part / Root.
  - **Shoresh** (שורש) = Root.
  - **Char** (חר) = Hole/Pit? Or **Kar** (כר) = Pasture?
  - Could be **Qar** (Cold)?
  - Given visual evidence, **Root** is the strongest functional candidate.
  - Phonetic: `char` -> *Chor* (Hole/Pit - where the root goes?). Or *Gzar* (Carrot/Cut)?
  - **Proposed Meaning**: **Root**.

## Conclusion
- **`chol`** likely means **Leaf** (or is a descriptor for foliage/greenery).
- **`char`** likely means **Root** (or distinct underground part).
- These hypotheses should be tested by translating sentences with `qokchol` ("With the leaves...") and `qokchar` ("With the root...") to see if the context holds.
