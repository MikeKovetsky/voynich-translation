# Voynich Manuscript Research Project

## Overview
This project aims to decode and translate the Voynich Manuscript. Our research has identified the manuscript as a **Medieval Medical Protocol** organized by Zodiac rulership.

## Key Findings
- **Medical Protocol:** The text describes the preparation of herbal remedies ("Cures") using heat and cooking processes.
- **Language Structure:** The script functions as a structured language with consistent grammatical rules for recipes (Imperative verbs, Ingredient markers).
- **Botanical Identification:** We have identified several plants, including Coriander and Chicory, and linked them to their astrological properties.
