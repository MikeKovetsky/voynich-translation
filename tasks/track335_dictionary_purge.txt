# Task: Dictionary Purge & Sanitization
# Status: Pending
# Goal: Clean 'results/dictionary/master_dictionary_v19.json' of parser artifacts.

Description:
The master dictionary contains garbage keys like "!!!!!!!!!!!!!!!!!!!!!ytai!n" and "!!!!!ky!deedy". 
These are likely artifacts from the tokenizer failing to handle punctuation or '!' markers in the raw text.

Requirements:
1. Create a script `research/sanitize_dictionary.py`.
2. Load `results/dictionary/master_dictionary_v19.json`.
3. Filter out entries where the key:
    - Contains "!" or "?" or other non-Voynich characters (valid chars: a-z, 0-9, maybe '*').
    - Is longer than 15 characters (Voynich words are rarely that long).
    - Is empty.
4. Save the clean dictionary to `results/dictionary/master_dictionary_v20.json`.
5. Produce a report `results/sanitization_report.md` listing how many entries were removed and providing examples of removed keys.
6. Calculate the new "Clean Coverage" on Quire 20 using this v20 dictionary.

Output:
- results/dictionary/master_dictionary_v20.json
- results/sanitization_report.md
