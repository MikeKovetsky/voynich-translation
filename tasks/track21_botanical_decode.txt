Apply the confirmed Latin phonetic mapping to ALL botanical/herbal pages

================================================================================
CONFIRMED PHONETIC MAP (USE THIS):
================================================================================

CONFIRMED (90%+ confidence):
  o → a
  h → r
  9 → s (or -us/-is at word end)
  k → n
  c → c
  7 → l
  m → m

STRONG (75%+ confidence):
  4 → qu
  1 → t
  8 → d
  a → e
  e → i
  2 → b
  y → i

ABBREVIATION EXPANSIONS:
  -9  → -us/-is (nominative)
  -89 → -orum/-arum (genitive plural)
  -am → -am (accusative feminine)
  -oe → -ae (dative/ablative)
  -ay → -i (dative singular)
  -an → -um (accusative/ablative)

================================================================================
INPUT DATA:
================================================================================

1. /voynich_raw.txt - Full Glen Claston v101 transcription
2. /results/latin_abbreviation_test.json - Latin vocabulary reference
3. /results/f17r_decoded.json - Example decoded page

================================================================================
TASKS:
================================================================================

1. EXTRACT ALL BOTANICAL PAGES
   Parse voynich_raw.txt to extract text from:
   - f1r through f57r
   - Skip non-botanical folios
   - Record page boundaries and line counts

2. DECODE EACH PAGE
   For each botanical page:
   - Apply phonetic mapping to all words
   - Apply abbreviation expansions
   - Track decoded text

3. SCORE LATIN COVERAGE
   For each decoded word, check against Latin vocabulary:
   
   A) EXACT MATCH: Word matches known Latin term
   B) STEM MATCH: Word stem matches (ignoring endings)
   C) PHONETIC MATCH: Consonant skeleton matches Latin
   D) NO MATCH: No recognizable Latin
   
   Calculate percentage for each category.

4. IDENTIFY COMMON PATTERNS
   Across all botanical pages:
   - What are the most common decoded words?
   - What decoded words appear on >50% of pages?
   - Are there consistent entry structures?

5. FIND PLANT NAME CANDIDATES
   First word/phrase of each page entry is likely plant name:
   - Extract first 1-3 words of each page
   - Decode and compare to Latin plant names
   - Score matches

6. COMPARE PAGE LENGTHS
   - Do shorter pages decode differently than longer ones?
   - Any correlation between page length and Latin match rate?

7. STATISTICAL SUMMARY
   Calculate overall statistics:
   - Total words decoded
   - % matching Latin vocabulary
   - % with Latin-like structure
   - Most/least successful pages
