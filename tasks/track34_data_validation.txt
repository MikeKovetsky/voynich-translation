# Track 34: Fundamental Data Validation

## OBJECTIVE
Validate and fix fundamental data quality issues that may be causing analysis failures.

## CRITICAL FINDING
TWO DIFFERENT TRANSCRIPTION SYSTEMS ARE IN USE:

| File | System | Example First Line |
|------|--------|-------------------|
| `voynich_raw.txt` | **Claston** | `fa19s.9,hae.ay.Akam.2oe` |
| `data/eva_ivtff.txt` | **EVA** | `fachys.ykal.ar.ataiin.shol` |

**This could explain ALL analysis failures!**

## INPUT FILES
- `voynich_raw.txt` - Claston transcription
- `data/eva_ivtff.txt` - EVA transcription (IVTFF format)

## KNOWN ISSUES

### 1. Different Scripts Use Different Files
| Script | Data File | Transcription System |
|--------|-----------|---------------------|
| `eva_analysis.py` | `eva_ivtff.txt` | EVA (H transcriber) |
| `botanical_decode.py` | `voynich_raw.txt` | Claston |
| `sentence.py` | ? | ? |
| `verb_context.py` | ? | ? |

### 2. Phonetic Map Designed for Claston
In `botanical_decode.py`:
```python
PHONETIC_MAP = {
    'o': 'a', 'h': 'r', '9': 's', 'k': 'n', ...
}
```
This maps Claston `9` → `s`, but EVA uses `y` for the same character!

### 3. EVA File Has Multiple Transcribers
The EVA file has versions from: H, C, F, N, U, m, c
- Which one are we using consistently?
- Do they differ significantly?
