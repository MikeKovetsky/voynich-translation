# Status: Completed
# Goal: Check if plants with the same Medical Use share the same unique words.

Description:
If `chol` means "Stomach Medicine", it should appear on all "Stomach Plants" (Mint, Fennel, etc.).
We will group the Sherwood plants by their medieval use cases and check for vocabulary overlap.

Requirements:
1. Create `research/functional_clusters.py`.
2. Define clusters:
    - **Stomach:** Mint, Fennel, Dill, Coriander.
    - **Head/Sleep:** Poppy, Valerian, Lettuce.
    - **Skin/Wound:** Plantago, Aloe, Comfrey.
    - **Women:** Mugwort, Peony? (Need to check Sherwood list).
3. For each Cluster:
    - Collect all words from the corresponding pages.
    - Find the **Intersection** (words present in >70% of the cluster).
    - Check if these intersection words are unique to this cluster (not generic words like `daiin`).
4. Output `results/functional_cluster_words.csv`.

Output:
- research/functional_clusters.py
- results/functional_cluster_words.csv

Results:
- Stomach: No unique words found >70% intersection.
- Women: No unique words found >70% intersection.
- Head/Sleep: `sho` (86%), `chy` (86%), `chor` (71%).
- Skin/Wound: `sho` (80%).
`sho` appears to be a shared term between Head/Sleep and Skin/Wound clusters.
