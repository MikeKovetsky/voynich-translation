# Task: Suffix Stripping v3 (Grounded Morphology)
# Status: Pending
# Goal: Learn the grammar using the Gold Anchors.

Description:
Once we have "Gold Anchors" (e.g., `pis` = Pea), we can verify suffixes.
If we find `pis-ol` on the page, and we know `pis` is the root, then `-ol` MUST be a suffix (or particle).
This is "Supervised Learning" of morphology.

Requirements:
1. Create `research/grounded_suffix_stripper.py`.
2. Load `results/gold_anchors.csv`.
3. For each Gold Anchor Root (e.g., `pis`):
    - Search the ENTIRE manuscript for words starting with that root.
    - Collect the "Remainders" (e.g., `pis-ol` -> `ol`, `pis-y` -> `y`).
    - Count the frequency of these remainders.
4. Identify the "Top 10 Proven Suffixes".
5. Produce `results/proven_suffixes.json`.
6. Update the Master Dictionary v20 to v21:
    - Add the Gold Anchors (Confidence 1.0).
    - Add the Proven Suffixes as grammatical modifiers.

Output:
- research/grounded_suffix_stripper.py
- results/proven_suffixes.json
- results/dictionary/master_dictionary_v21.json
