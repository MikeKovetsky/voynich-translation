# Goal: Create a translator from standard EVA to Sherwood's "AVA" (American Voynich Alphabet).

Description:
Edith Sherwood uses a visual mapping alphabet (AVA). To test her theories, we must translate our EVA corpus into AVA.
Based on her article:
- EVA `o` -> AVA `o`
- EVA `a` -> AVA `a`
- EVA `e` -> AVA `e`
- EVA `i` -> AVA `i`
- EVA `8` (d) -> AVA `b` (looks like 8) -> Wait, usually EVA `8` is `d`. Sherwood says "8-shaped symbol represents b". In EVA `8` is `d`. Let's map EVA `d` -> AVA `b`.
- EVA `9` (y) -> AVA `a` (at start/end) or `m`? She says "9-shaped symbol... may also represent a".
- EVA `l` -> AVA `l`
- EVA `p` -> AVA `p`
- EVA `s` -> AVA `s`
- EVA `g` -> AVA `g`?

Requirements:
1. Create `research/eva_to_ava.py`.
2. Define the mapping dictionary based *strictly* on her Table 4 and text.
    - Need to be careful: EVA uses `d`, `y`, `l`, `r` etc.
    - We need to map EVA glyphs to her "Latin" interpretation.
3. Function `to_ava(eva_text)` that returns the Italian-like string.
4. Output `data/ava_sample.txt` (A converted version of f4r and f37v).

Output:
- research/eva_to_ava.py
