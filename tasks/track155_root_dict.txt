Task: Root Dictionary Alignment

We have a dictionary of "Words" (v7.4). We need a dictionary of "Roots".

Input:
- results/unified_dictionary.json (The old word-based dict)
- results/root_mapping.json (Or the output of Task 153)

Subtasks:
1. **Map Words to Roots:**
   - If we know `chol` = "Leaf", and `chol` is a root.
   - And we parse `ychol` -> `y-` + `chol`.
   - Then the root `chol` means "Leaf".
   - But what if `qokeedy` = "Mixture"? And `keed` is the root? Does `keed` mean "Mix"?

2. **Conflict Resolution:**
   - If `word A` -> `root R` (Meaning X)
   - And `word B` -> `root R` (Meaning Y)
   - We have a collision. `root R` cannot mean both X and Y (unless they are related).
   - Identify these collisions.

3. **Create Root Dict:**
   - Generate `results/root_dictionary_v1.json`.
   - Format: `{"root": "keed", "meanings": ["Mixture", "Liquid"], "source_words": ["qokeedy", "okeedy"]}`.

Output:
- `results/root_dictionary_v1.json`
