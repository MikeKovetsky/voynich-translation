# Goal: Determine word types (Noun/Verb/Particle) based on sentence position.

Description:
Semantic matching failed. We need to rely on Syntax.
In many languages, the First Word is a Particle/Connector, and the Last Word is a Verb or Object.
We will calculate the Entropy (unpredictability) of each position.

Requirements:
1. Create `research/positional_entropy.py`.
2. Load the entire Voynich corpus (EVA).
3. Segment into sentences (using `.` or paragraph breaks).
4. For each position (1, 2, 3... Last):
    - Collect all words that appear in that position.
    - Calculate Shannon Entropy: -Sum(p * log2(p)).
5. Hypothesis:
    - Low Entropy = Closed Class (Prepositions, Particles).
    - High Entropy = Open Class (Nouns, Verbs).
6. Output `results/positional_entropy.csv` and a plot/report.
