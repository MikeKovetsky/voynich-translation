# Task: Visual-Text Validation (Descriptor Hunt)
# Status: Pending
# Goal: Validate pages where phonetic matching failed using Semantic Categories.

Description:
For the pages where we didn't find the name (e.g., *Drosera* not found), we look for **Descriptors**.
Sherwood describes *Drosera* as "Carnivorous", "Sticky", "Trap".
We need to see if the text contains words that might mean this.

Requirements:
1. Create `research/visual_descriptor_match.py`.
2. Define a list of "Expected Descriptors" for specific plant types:
    - Carnivorous: eat, kill, insect, sticky.
    - Aquatic (Water Lily): water, float, pond.
    - Poisonous (Nightshade): death, poison, pain.
3. Scan the Sherwood list for plants with these properties.
4. Scan the text of those pages for recurring words that are NOT plant names.
5. Hypothesis: If `chol` appears on 5 different "Poisonous" plant pages, `chol` might mean "Poison".
6. Output `results/descriptor_hypotheses.csv`.

Output:
- research/visual_descriptor_match.py
- results/descriptor_hypotheses.csv
