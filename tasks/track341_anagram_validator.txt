# Task: Anagram Validator
# Status: Completed
# Goal: Test Edith Sherwood's hypothesis that plant names are anagrams.

Description:
The direct phonetic match failed (0 anchors). Sherwood suggests the names are hidden as anagrams.
We need to check if the letters of the Latin name appear as a scramble in the Voynich text.

Requirements:
1. Create `research/anagram_validator.py`.
2. Load `data/external_corpora/sherwood_plant_mapping.csv`.
3. For each folio:
    - Get the Latin Name (e.g., "Pisum").
    - Get the Voynich Text (e.g., "daiin...").
    - **Test 1 (Full Anagram):** Is there any Voynich word that is an exact anagram of the Latin name? (Normalize length).
    - **Test 2 (Subset Anagram):** Is there any Voynich word that can be formed *using only* the letters from the Latin name?
    - **Test 3 (Super-set Anagram):** Can the Latin name be formed using the letters of a Voynich word?
4. Use the `phonetic_bridge` logic but for Anagrams (sorted letters match).
5. Output `results/anagram_candidates.csv`.

Output:
- research/anagram_validator.py
- results/anagram_candidates.csv
