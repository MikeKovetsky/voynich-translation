# Task 171: Cluster-Section Correlation

## Goal
Validate the 72 Noun Clusters found in Task 168 by checking their distribution across the manuscript's known sections (Herbal, Astronomical, Biological, Recipes, Rosettes).

## Input
- `results/noun_clusters.json` (Mapping: Word -> Cluster ID)
- `results/parsed_text.json` (Text grouped by Page ID)
- `results/topic_model.json` (Section definitions, if needed)

## Process
1.  **Map Pages to Sections:**
    - Herbal: f1r - f57v, f87r - f102v
    - Astronomical: f67r - f73v
    - Biological: f75r - f84v
    - Recipes: f103r - f116v
    - Rosettes: f85r - f86v
    - (Use standard Voynich section definitions).
2.  **Count Frequencies:**
    - For each Cluster ID, count how many times its member words appear in each Section.
    - Normalize by section length (words per section).
3.  **Identify Section-Specific Clusters:**
    - Which clusters appear *only* or *mostly* (>80%) in the Herbal section? Label them "Herbal Candidates".
    - Same for Astro, Bio, Recipes.

## Output
- `results/cluster_distribution.csv`: Table of Cluster ID vs. Section Frequencies.
- `results/cluster_validation_report.md`: Report identifying "Herbal Clusters", "Astro Clusters", etc.
- `results/track-171-results_summary.md`: Summary.
