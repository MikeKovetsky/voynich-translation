# Task: The Codebreaker (Multilingual Match)
# Status: Pending
# Goal: Map the unique TF-IDF keywords to actual plant names in various languages.

Description:
We have identified "Unique Keywords" for specific plants (e.g., `opchy` for Cannabis).
Now we check if these are phonetic matches in languages OTHER than Latin.

Requirements:
1. Create `research/codebreaker_multilang.py`.
2. Load `results/unique_page_keywords.csv`.
3. Define a target dictionary of plant names in:
    - Medieval German
    - Medieval Italian
    - Hebrew
    - Arabic (transliterated)
    - Greek
4. For each Folio/Keyword pair:
    - Compare the Keyword (and its Root, stripped of `o-` prefix) to the target names.
    - Use Fuzzy Matching (Levenshtein).
5. Focus on the Top 20 "Most Unique" keywords (highest TF-IDF score).
6. Output `results/multilang_matches.csv`.

Output:
- research/codebreaker_multilang.py
- results/multilang_matches.csv
