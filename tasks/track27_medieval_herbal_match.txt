## TASKS

### 1. Build Reference Vocabulary
From medieval herbal sources, extract:
- Top 100 botanical terms (plant parts)
- Top 50 medical terms (diseases, body parts)
- Top 30 preparation verbs
- Top 20 prepositions/conjunctions
- Common phrase patterns

### 2. Vocabulary Comparison
Compare decoded Voynich vocabulary with medieval herbal vocabulary:
- Exact matches
- Stem matches
- Phonetic near-matches
- Missing expected words

### 3. Phrase Pattern Comparison
Medieval herbals have predictable patterns:
```
"Herba [NAME] calida/frigida est"
"Valet contra [AILMENT]"
"Radix/Folium/Semen eius..."
"Recipe [AMOUNT] de [INGREDIENT]"
"Coque in aqua/vino"
"Bibitur/Datur cum [LIQUID]"
```

Search for these patterns in decoded Voynich.

### 4. Structure Comparison
Medieval herbal entries typically have:
1. Plant name
2. Physical description
3. Properties (hot/cold, wet/dry)
4. Medicinal uses
5. Preparation instructions
6. Dosage

Does Voynich text show this structure?

### 5. Statistical Comparison
Compare:
- Word length distributions
- Case ending frequencies
- Verb/noun ratios
- Preposition frequencies

### 6. Specific Word Search
Search decoded Voynich for expected medieval terms:
- `radix` (root) - WE CLAIM TO FIND THIS
- `folium` (leaf)
- `herba` (herb)
- `aqua` (water) - CONFIRMED
- `vinum` (wine)
- `mel` (honey)
- `contra` (against)
- `valet` (is effective)
- `curat` (cures)
- `sanat` (heals)
