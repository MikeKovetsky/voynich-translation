# Track 314: Blind Set Selection (The Control Group)
# Status: Ready for Execution
# Priority: Low (Setup)

## Goal
Select a "Control Group" of text for the upcoming Blind Translation test. These must be pages we have NOT analyzed heavily yet, to avoid bias.

## Requirements
1.  **Input:** `data/eva_ivtff.txt` + Page metadata (Density info).
2.  **Script:** `research/select_blind_set.py`
    -   Find 5 pages with "High Text Density" but "Low Image Content" (or ambiguous images).
    -   Exclude Quire 20 (Recipes) and Bio Section (f75-f84) as we are biased there.
    -   Likely candidates: The "Text-only" quires or the "Star Paragraphs".
    -   Extract their raw text into `data/blind_set_raw.txt`.

## Expected Output
1.  `data/blind_set_raw.txt`: The raw text to be translated later.
2.  `results/blind_set_manifest.md`: Why these pages were chosen.

## Why?
We need a clean dataset to test our translation engine later.
