================================================================================
TRACK 5: EVA TRANSCRIPTION COMPARISON
================================================================================

GOAL:
Obtain the standardized EVA (European Voynich Alphabet) transcription and
create a mapping to validate our analysis against the scholarly standard.

================================================================================
BACKGROUND CONTEXT:
================================================================================

Our current analysis uses the Glen Claston v101 transcription which uses
a custom notation. The academic standard is EVA (European Voynich Alphabet),
created by Gabriel Landini and others in 1998.

EVA provides:
- Standardized glyph names for all Voynich characters
- Consistent transcription across researchers
- Interoperability with other Voynich research

Mapping between transcription systems will:
1. Validate our statistical findings
2. Allow comparison with published research
3. Enable use of existing Voynich analysis tools

================================================================================
INPUT DATA AVAILABLE:
================================================================================

1. Glen Claston transcription: /voynich_raw.txt
   - Uses characters: o, 9, a, c, 1, e, 8, h, y, k, 4, m, 2, C, 7, s, n, p, K, g, etc.
   - Contains ~170 unique character symbols

2. EVA specification:
   - Available at: https://www.voynich.nu/extra/eva.html
   - Uses lowercase letters: a, c, d, e, f, g, h, i, k, l, m, n, o, p, q, r, s, t, y
   - Special characters for gallows letters, bench characters, etc.

================================================================================
SPECIFIC TASKS:
================================================================================

1. OBTAIN EVA TRANSCRIPTION
   
   Sources to try:
   - René Zandbergen's site: https://www.voynich.nu/
   - GitHub repositories with EVA transcriptions
   - Stolfi's EVMT corpus
   - IVTFF format files
   
   Required: Complete page-by-page transcription in EVA format

2. BUILD CHARACTER MAPPING
   
   Create mapping between Claston and EVA notations:
   - Analyze character frequencies in both systems
   - Match by frequency (most common in Claston = most common in EVA)
   - Validate by positional distribution
   - Handle special cases (capitals, punctuation)
   
   Expected mapping structure:
   CLASTON -> EVA
   'o' -> 'o' (most common, likely same)
   '9' -> 'y' (word-final)
   '4' -> 'q' (word-initial, often with 'o')
   'c' -> 'ch' or 'sh'?
   '8' -> 'd'?
   etc.

3. VALIDATE MAPPING
   
   For each page:
   - Convert Claston to EVA using mapping
   - Compare with official EVA transcription
   - Calculate accuracy percentage
   - Identify discrepancies

4. RE-RUN ANALYSIS WITH EVA
   
   Apply our analysis scripts to EVA transcription:
   - Character frequencies
   - Word patterns
   - Grammar analysis
   - Compare results with Claston-based analysis

5. CROSS-REFERENCE WITH PUBLISHED RESEARCH
   
   Using EVA transcription:
   - Verify our findings against published statistics
   - Check if our "PREFIX+ROOT+SUFFIX" structure is visible in EVA
   - Validate the 37% word-final character (should be 'y' in EVA)
