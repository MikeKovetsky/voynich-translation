Task: Final Translation v10 (The Clean Run)

We have a clean morphological parse and a root dictionary. Let's produce the best translation yet.

Input:
- results/parsed_text.json
- results/root_dictionary_v1.json

Subtasks:
1. **Translation Logic:**
   - **Prefixes:**
     - `qok-` / `qo-` -> "To [Action]" (Verb)
     - `d-` / `dai-` -> "Take/From" (Imperative/Prep)
     - `y-` -> "And"
     - `o-` / `ol-` -> "The/Of"
     - `s-` -> "Which/That"
   - **Roots:**
     - Lookup in `root_dictionary_v1.json`.
     - If root is `ee` or `dy` (very common), leave as variable `[X]` or `[Y]` if unknown, or use best guess.
     - `dy` -> "Light/One"? `ee` -> "Do/Make"?

2. **Process:**
   - Translate the entire manuscript (or a large sample).
   - Format: `[Prefix Meaning] [Root Meaning]`.

3. **Output:**
   - `results/translation_v10.md`

This is the culmination of the "Morphological Pivot".
