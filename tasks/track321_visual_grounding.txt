# Track 321: Visual-Root Grounding & Artifact Expansion
# Status: Ready for Execution
# Priority: Medium

## Goal
Link the Top Roots to visual themes and create artifacts for visual correlations.

## Requirements
1.  **Input:** `data/eva_ivtff.txt` + Page Metadata (which pages are "Bio", "Astro", "Herbal").
2.  **Script:** `research/visual_root_linker.py`
    -   Calculate the "Section Distribution" for each of the Top 50 Roots.
    -   Does Root X appear 90% of the time in "Astro"? -> Tag as `[ASTRO_TERM]`.
    -   Does Root Y appear 90% of the time in "Bio"? -> Tag as `[BIO_TERM]`.
    -   **Artifact Generation:**
        -   Write `artifacts/roots_by_section.csv`: `Root, PrimarySection, Frequency, Confidence`.

## Expected Output
1.  `results/visual_root_link_report.md`:
    -   List of "Specialized Roots" (Section-specific).
    -   List of "General Roots" (Omnipresent).
2.  `artifacts/roots_by_section.csv`: Reusable CSV for the dictionary patcher.

If `qok` is only in Recipes, it's a cooking term. If it's everywhere, it's a common verb like "is" or "make".
