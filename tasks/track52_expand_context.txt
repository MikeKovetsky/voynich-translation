# Track 52: Expand Dictionary - Context Analysis

## OBJECTIVE
Use surrounding word context to deduce meanings of unknown words.
If we know what words appear before/after an unknown, we can infer its meaning.

## INPUT FILES
- `results/hybrid_dictionary.json` - Current dictionary
- `results/grammar_words.json` - Grammar analysis
- `results/recipe_translation.json` - Recipe contexts
- `data/eva_ivtff.txt` - Source text

## METHODOLOGY

### The Context Principle
If unknown word X consistently appears in pattern:
```
[known_word_A] X [known_word_B]
```
We can infer X's meaning from A and B.

Example:
```
"heart X salt" appears 5 times
"heart X fig" appears 3 times
If X is always between body_part and ingredient:
→ X might mean "with" or "and" or a verb
```

## TASKS

### 1. Build Context Database

For every word in corpus:
- Record word before (W-1)
- Record word after (W+1)
- Record 2-word context (W-2, W+2)
- Note position in line (start/middle/end)

### 2. Find Pattern-Rich Unknown Words

Identify unknowns that:
- Have consistent context patterns
- Appear with known words frequently
- Show positional regularity

### 3. Analyze Specific Patterns

#### Pattern A: Between Two Knowns
```
[heart] X [fig] → X = "with/and"?
[earth] X [salt] → X = "and"?
```

#### Pattern B: After Known, Before Suffix
```
[heart] X -y → X = adjective?
[fig] X -dy → X = verb?
```

#### Pattern C: After Prefix, Before Known
```
qo- X [heart] → X = modifier?
ch- X [fig] → X = action?
```

### 4. Verb Identification

Look for words that:
- Appear at line END (SOV pattern)
- Follow objects (nouns)
- Have verb-like suffixes (-dy, -edy)

Candidate verbs:
- Words ending in `-edy` after ingredients
- Words at sentence boundaries
- Words with `ch-` prefix (imperative?)

### 5. Adjective Identification

Look for words that:
- Appear between article and noun
- Modify known nouns consistently
- Have adjective-like endings

### 6. Build Inferred Dictionary

For each inferred word:
```json
{
  "word": "lchedy",
  "inferred_meaning": "mix/combine",
  "evidence": "appears after ingredients, before '-y' suffix",
  "confidence": 0.5,
  "context_examples": [
    "fig lchedy salt-y",
    "heart lchedy earth-y"
  ]
}
```
