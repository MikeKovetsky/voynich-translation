### 2. Apply Grammar Model
From Track 49:
- `ol/al` = "the" (article)
- `ar` = "to/at" (preposition)
- `daiin/aiin` = "is/from" (copula, LINE END)
- `-y/-dy` = verb suffixes
- SOV word order

### 3. Full Translation Pipeline
For each line:
1. Tokenize into words
2. Look up each word in merged dictionary
3. Apply grammar rules
4. Attempt sentence reconstruction
5. Score coherence

### 4. Sentence Reconstruction
Use SOV pattern:
```
[Subject] [Object] [Verb]
Example: "heart fig treat" → "treat the heart with fig"
```

Medieval recipe patterns:
- "Take X" (imperative)
- "Mix X with Y"
- "Apply to Z"
- "For condition W"

### 5. Calculate Metrics
- **Word Translation Rate**: % words with dictionary match
- **Sentence Coherence**: Does sentence make sense?
- **Recipe Pattern Match**: Does it look like a recipe?

### 6. Identify Best Sentences
Find lines with:
- >50% word translation rate
- Coherent meaning
- Recipe-like structure
