================================================================================
TRACK 20: PHRASE PATTERN ANALYSIS
================================================================================

GOAL:
Move beyond word-by-word decoding to identify multi-word Latin phrases
that appear consistently across the manuscript.

================================================================================
RATIONALE:
================================================================================

Individual words decode to Latin-LIKE text, but sentences aren't readable.
However, PHRASE patterns may be more recognizable:

- "de + NOUN" → "of/from X"
- "ad + NOUN" → "to/for X"  
- "in aqua" → "in water"
- "cum vino" → "with wine"
- "contra + DISEASE" → "against X"

================================================================================

================================================================================

================================================================================
CONFIRMED PHONETIC MAP:
================================================================================

o→a  h→r  9→s  k→n  c→c  7→l  m→m  4→qu  1→t  8→d  a→e  e→i  2→b  y→i

Known Voynich → Latin:
- o4o → aqua (water) - PERFECT MATCH
- 8am/8ay/8ae → de (of/from) - HIGH CONFIDENCE
- oh9 → ars ≈ aries - CONFIRMED

3. SEARCH FOR TRIGRAMS

4. FIND "8am/de" PATTERNS
   Since 8am = "de" (of/from):
   - Find all "8am + X" sequences
   - Decode X
   - Check if X is a noun (plant part, body part, etc.)
   
   Expected patterns:
   - "8am radice" (of the root)
   - "8am herba" (of the herb)
   - "8am aqua" (of water)

5. FIND "o4o/aqua" PATTERNS
   Since o4o = "aqua":
   - Find all "X + o4o" sequences
   - Find all "o4o + X" sequences
   - Decode and identify patterns like "in aqua"

6. VALIDATE WITH POSITION
   Preparation phrases should appear:
   - Later in herbal entries (after description)
   - Near other preparation words
   
   Check if found phrases appear in expected positions.
