# Track 46: Constructed Language / Cipher System Analysis

## OBJECTIVE
Test if Voynich is a deliberately CONSTRUCTED system rather than a natural language.
Compare against known medieval cryptographic and esoteric traditions.

## INPUT FILES
- `data/eva_ivtff.txt` - Source transcription
- `results/hebrew_analysis.json` - Structural patterns
- `results/glyph_analysis.json` - Glyph properties

## BACKGROUND
Track 41 found: "Different encoding system that shares structural features with Semitic languages"
This suggests intentional construction rather than natural language.

Medieval constructed systems include:
- Trithemius cipher (1508)
- Roger Bacon's cipher proposals
- Alchemical notation
- Secret society codes
- Angelic/Enochian scripts

## TASKS

### 1. Test for Cipher Characteristics

#### 1a. Regularity Test
Natural languages have irregularities. Constructed systems are more regular.
- Measure word length distribution variance
- Check for overly consistent patterns
- Compare to natural language baselines

#### 1b. Entropy Analysis
- Calculate Shannon entropy
- Compare to known ciphered texts vs plain texts
- Is it too regular or too random?

### 2. Medieval Cipher Comparison

#### 2a. Trithemius System
Compare Voynich patterns to Johannes Trithemius's "Polygraphia" (1508):
- Substitution tables
- Steganographic techniques

#### 2b. Alchemical Notation
Check for alchemical symbol patterns:
- Element symbols (🜍 sulfur, 🜔 mercury, etc.)
- Process terms (calcination, dissolution, etc.)
- Do Voynich sections match alchemical stages?

#### 2c. Null Cipher Test
Are some characters/words meaningless "nulls"?
- Check for characters that add no information
- Test if removing certain glyphs improves readability

### 3. Artificial Grammar Detection

#### 3a. Markov Analysis
- Build character/word transition probabilities
- Is the grammar too simple (low-order Markov)?
- Natural languages need higher-order models

#### 3b. Zipf's Law Test
- Does word frequency follow Zipf's law?
- Deviations suggest constructed origin

### 4. Pattern Injection Test
Check if patterns were deliberately inserted:
- Repeating sequences
- Palindromic structures
- Mathematical relationships (Fibonacci, etc.)

### 5. Compare to Known Constructed Languages
- Hildegard von Bingen's "Lingua Ignota" (12th c.)
- John Dee's Enochian (16th c.)
- Are there structural similarities?

### 6. Encoding Layer Analysis
Test for multiple encoding layers:
- Simple substitution (letter-for-letter)
- Syllabic encoding (symbol-for-syllable)
- Word-level encoding (symbol-for-word)
- Combination systems
