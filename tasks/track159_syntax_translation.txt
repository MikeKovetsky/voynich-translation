Task: Syntax-Based Translation (The New Translator)

We have Roots (Task 155) and Grammar (Task 158). Let's combine them to attempt a new translation.

Input:
- results/tagged_text.txt
- results/root_dictionary_v1.json

Subtasks:
1. **Translation Map:**
   - Map Tags:
     - `VERB` -> "[Action]"
     - `IMP` -> "Take/Do"
     - `CONJ` -> "and"
     - `NOUN` -> "the"
   - Map Roots:
     - Use meanings from `root_dictionary_v1.json` (e.g., `chol` -> "leaf").

2. **Translate Sample Pages:**
   - Select 10 diverse pages (Herbal, Recipes, Bio).
   - Translate them using the structure: `[Tag Meaning] [Root Meaning]`.
   - Example: `qo-keedy` -> `[Action] Mixture`. `y-chol` -> `and Leaf`.

3. **Evaluation:**
   - Does the syntax make sense? "Take the leaf and boil the root"?
   - Or is it still word soup?

Output:
- `results/syntax_translation_sample.md`
