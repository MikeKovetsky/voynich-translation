# Task: The "Null" Hypothesis (Markov Test)
# Status: Pending
# Goal: Test if the text is indistinguishable from a Markov Chain (Random Generation).

Description:
Could the manuscript be a 15th-century hoax generated by a word table?
We will generate text using a 2nd-order Markov Model trained on Voynich.
We will compare the "Generated" text to the "Real" text using statistical metrics (Zipf's Law, Word Length Distribution).
If they are identical, the text might be generated.

Requirements:
1. Create `research/markov_test.py`.
2. Train a Markov Chain on the first half of the manuscript.
3. Generate 50 pages of "Fake Voynich".
4. Compare "Fake" vs "Real" (Second half) using:
    - Word Entropy.
    - Zipf Slope.
    - Repeat Rate (how often `word` follows `word`).
5. Output `results/markov_comparison.md`.

Output:
- research/markov_test.py
- results/markov_comparison.md
