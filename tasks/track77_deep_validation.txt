TRACK 77: Deep Word-by-Word Validation
======================================

GOAL: Pick specific folios with expert plant IDs and do word-by-word accuracy test.

INPUT FILES:
- data/eva_ivtff.txt
- results/master_dictionary.json
- results/quire_01_02_plants.json
- results/scholarly_master_report.md

TARGET FOLIOS (high confidence expert IDs):
| Folio | Expert ID | Confidence | Why Selected |
|-------|-----------|------------|--------------|
| f9v | viola (pansy) | HIGH | "Most recognizable plant" |
| f51r | ricinus (castor) | HIGH | Clear expert consensus |
| f6v | ricinus (castor) | HIGH | Same plant, different folio |
| f16r | cannabis (hemp) | HIGH | Clear identification |
| f7r | paeonia | MEDIUM | Expert ID available |

TASK 1: Extract ALL Words from Target Folios
--------------------------------------------
For each target folio:
- Extract every word from eva_ivtff.txt
- Note position (paragraph, line, label)
- Preserve word order

Format:
{
  "folio": "f9v",
  "expert_id": "viola",
  "words": [
    {"position": "P1.L1.W1", "word": "...", "our_translation": "...", "expected": "..."},
    ...
  ]
}

TASK 2: Apply Our Dictionary
----------------------------
For each word:
1. Look up in master_dictionary.json
2. Record translation (if found)
3. Mark unknown words

TASK 3: Build Expected Vocabulary
---------------------------------
Based on expert plant ID, what words SHOULD appear?

For f9v (viola/pansy):
- Plant name: viola, סגל, vl/sgl
- Flower terms: flower, petal, purple, yellow
- Leaf terms: leaf, heart-shaped
- Root terms: root
- Botanical terms: annual, herb

TASK 4: Calculate Accuracy Metrics
----------------------------------
For each folio:
| Metric | Count |
|--------|-------|
| Total words | N |
| Dictionary matches | N |
| Correct translations | N |
| Incorrect translations | N |
| Unknown words | N |
| Accuracy | X% |

TASK 5: Error Analysis
----------------------
For incorrect translations:
- What did we say?
- What should it be?
- Why the mismatch?

Categories:
- Wrong plant name
- Wrong plant part
- Grammar word confusion
- Complete miss

TASK 6: Propose Corrections
---------------------------
Based on errors found, suggest:
- Dictionary corrections
- New entries
- Confidence adjustments

OUTPUT FILES (REQUIRED):
- deep_validate.py
- results/deep_validation.json:
  {
    "folios_tested": 5,
    "total_words": N,
    "accuracy": X%,
    "per_folio_results": [...],
    "error_analysis": [...],
    "corrections_proposed": [...]
  }
- results/deep_validation_report.md:
  - Word-by-word breakdown for each folio
  - Accuracy metrics
  - Error categories
  - Proposed corrections
