# Task 175: Recipe Decoding

## Goal
Attempt a "Semantic Translation" of the Recipe Section (Quire 20, f103r-f116v) using our specific "Lab Notebook" hypothesis.

## Input
- `results/parsed_text.json` (Filter for Recipe pages)
- `results/root_dictionary_v3.json`
- `results/noun_clusters.json`

## Translation Rules
1.  **Verbs:**
    - `qok-ed-y` -> "PROCESS!" (or "MIX!")
    - `qok-[root]-y` -> "[ACTION]!"
2.  **Nouns:**
    - Replace Cluster IDs with placeholders: `[Ingredient A]`, `[Liquid B]`.
    - `ol [Noun]` -> "the [Noun]"
    - `ar [Noun]` -> "with [Noun]" (or "to [Noun]")
3.  **Structure:**
    - Treat `dy` (stand-alone) or paragraphs as step separators.

## Process
1.  Extract all Recipe pages.
2.  Apply the translation rules.
3.  Look for patterns: "Take [Ingredient], Mix with [Liquid], Heat."

## Output
- `results/recipe_translation_v3.md`: The new translation.
- `results/recipe_logic.md`: Analysis of the "steps" found.
- `results/track-175-results_summary.md`: Summary.
