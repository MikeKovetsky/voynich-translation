# Track 313: Syntax Heatmap & Positional Analysis
# Status: Ready for Execution
# Priority: Medium

## Goal
Visualize where "High Confidence" words appear in a sentence. If `qokeey` is a verb, it should appear at the start (Imperative) or second position (Declarative), but rarely at the end.

## Requirements
1.  **Input:** `data/eva_ivtff.txt`.
2.  **Script:** `research/syntax_heatmap.py`
    -   Take top 20 High Confidence words (`qokeey`, `ol`, `daiin`, `sal`, `chol`, etc.).
    -   For each word, calculate the distribution of its position in a line (Position 1, 2, 3, ..., Last).
    -   Generate a text-based heatmap or CSV.

## Expected Output
1.  `results/syntax_heatmap.md`:
    -   Table showing the "Preferred Position" of key words.
    -   Example: `qokeey`: 80% Position 1 (Recipe), 10% Position 2 (Narrative).
    -   Example: `sal` (Salt): 90% End of Sentence (Object).

## Why?
This validates "Parts of Speech" without knowing the meaning. Verbs move differently than Nouns.
