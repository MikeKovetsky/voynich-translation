# Track 32: Unified Key Synthesis & Test

## OBJECTIVE
Combine derivations from Track 30 (zodiac) and Track 31 (plants) into a unified key, then rigorously test it.

## BACKGROUND
If zodiac and plant derivations produce consistent mappings, we may have found the correct key.
If they conflict, we learn important information about what the encoding IS and ISN'T.

## INPUT FILES
- `results/zodiac_key_derivation.json` - From Track 30
- `results/plant_key_derivation.json` - From Track 31
- `results/phonetic_key_validation.json` - Original key validation
- `results/master_dictionary.json` - Previous dictionary

## TASKS

### 1. Merge Derived Keys
Combine zodiac and plant derivations:
```json
{
  "o": {
    "zodiac_derived": "a",
    "plant_derived": "a", 
    "original_key": "a",
    "consensus": "a",
    "confidence": 0.95
  },
  "k": {
    "zodiac_derived": "p",
    "plant_derived": "n",
    "original_key": "n",
    "consensus": "CONFLICT",
    "confidence": 0.0
  }
}
```

### 2. Resolve Conflicts
For each conflicting character:
- Count supporting evidence for each value
- Check which produces more valid Latin words
- Make principled decision or mark as "uncertain"

### 3. Build Final Unified Key
Create the best possible key from all evidence:
- High-confidence mappings (all sources agree)
- Medium-confidence (2/3 sources agree)
- Low-confidence (1/3 sources or conflicts)

### 4. Full Corpus Test with New Key
Apply unified key to:
- ALL zodiac labels → recalculate match rate
- ALL plant labels → recalculate match rate
- Full botanical section → new Latin match rate
- Sample sentences → coherence scores

### 5. Compare with Original Key
| Test | Original Key | Unified Key | Change |
|------|--------------|-------------|--------|
| Zodiac match | 60-85% | ?% | ? |
| Plant match | 0.9% | ?% | ? |
| Medieval vocab | 2.2% | ?% | ? |
| Coherence | 37.9% | ?% | ? |

### 6. Verdict
Based on results, conclude:
- Is the unified key better?
- If yes, adopt it as new standard
- If no, what does this tell us about the encoding?
