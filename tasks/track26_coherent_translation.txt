# Track 26: Coherent Translation Attempt

## OBJECTIVE
Take the best-performing page and attempt to produce a READABLE Latin translation sentence by sentence.

## BACKGROUND
We have:
- 99.2% "Latin match rate" across botanical section
- 924 dictionary entries (71 high-confidence)
- SVO word order identified
- Verb candidates identified
- BUT: Max coherence score only 37.5%

The question: Can we actually READ any of it?

## INPUT FILES
- `results/master_dictionary.json` - All mappings
- `results/high_confidence_words.json` - Best mappings only
- `results/sentence_structure.json` - Sentence boundaries
- `results/verb_context.json` - Verb candidates
- `results/botanical_decoded.json` - Decoded words
- `data/eva_ivtff.txt` - Source transcription

## TASKS

### 1. Select Best Page
Choose page with highest:
- Latin match rate
- Number of high-confidence words
- Clear paragraph structure
- Identifiable plant illustration

Candidates: f2v (100%), f3v (100%), f4r (100%)

### 2. Full Sentence-by-Sentence Decode
For the selected page:
- Extract all text
- Segment into sentences using Track 22 boundaries
- Decode each word using master dictionary
- Mark confidence level of each word

### 3. Grammar Analysis Per Sentence
For each sentence identify:
- Subject (noun + case ending)
- Verb (from Track 23 candidates)
- Object (if present)
- Prepositions and their objects
- Adjective-noun pairs

### 4. Latin Reconstruction Attempt
For each sentence:
- Rearrange words to Latin grammar
- Expand abbreviations
- Fill in likely missing words
- Propose Latin reading

### 5. Medieval Herbal Comparison
Compare decoded sentences with known medieval herbal patterns:
- "Herba X valet contra Y" (Herb X is effective against Y)
- "Radix eius curat Z" (Its root cures Z)
- "Recipe folium..." (Take the leaf...)
- "Coque in aqua" (Cook in water)

### 6. Coherence Scoring
For each attempted translation:
- Does it make botanical/medical sense?
- Does it match illustration?
- Does grammar parse correctly?
- Score 0-100%
