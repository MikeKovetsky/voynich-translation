================================================================================
TRACK 9: ZODIAC MONTH NAME EXTRACTION & VALIDATION
================================================================================

GOAL:
The zodiac pages have 12 sections with ~30 labels each. Month names MUST appear
somewhere. This is a CONTROLLED TEST with known expected answers.

================================================================================
CRITICAL CONTEXT:
================================================================================

From results/zodiac_analysis.json, we have:
- Pisces (f70v2): 139 words → March
- Aries (f70v1, f71r): ~90 words each → April
- Taurus (f71v, f72r1): ~105 words each → May
- Gemini (f72r2): 112 words → June
- Cancer (f72r3): 173 words → July
- Leo (f72v3): 127 words → August
- Virgo (f72v2): 112 words → September
- Libra (f72v1): 105 words → October
- Scorpio (f73r): 93 words → November
- Sagittarius (f73v): 97 words → December

Total: ~1200 words across zodiac sections

Words appearing in 5+ signs are likely grammatical (okc9, okcc9, 8am)
Words UNIQUE to one sign might be month names or constellation names!

================================================================================
INPUT DATA:
================================================================================

1. /results/zodiac_analysis.json - All labels per zodiac section
2. /voynich_raw.txt - Full transcription for context
3. Month names in candidate languages to test

================================================================================
SPECIFIC TASKS:
================================================================================

1. EXTRACT UNIQUE LABELS PER SECTION
   - From zodiac_analysis.json, identify words appearing in ONLY ONE zodiac section
   - These are most likely to be:
     * Month name
     * Constellation name (zodiac sign name)
     * Specific star names
   - Create list: {zodiac_sign, unique_words[], word_count}

2. GET MONTH NAMES IN ALL CANDIDATE LANGUAGES
   
   LATIN (medieval):
   - Martius, Aprilis, Maius, Iunius, Iulius, Augustus
   - September, October, November, December, Ianuarius, Februarius

   BASQUE:
   - Martxoa, Apirila, Maiatza, Ekaina, Uztaila, Abuztua
   - Iraila, Urria, Azaroa, Abendua, Urtarrila, Otsaila

   HUNGARIAN:
   - Március, Április, Május, Június, Július, Augusztus
   - Szeptember, Október, November, December, Január, Február

   ITALIAN (medieval):
   - Marzo, Aprile, Maggio, Giugno, Luglio, Agosto
   - Settembre, Ottobre, Novembre, Dicembre, Gennaio, Febbraio

3. PHONETIC MATCHING TEST
   - Create character mapping from Voynich → Latin/Romance phonemes
   - Apply to unique labels in each zodiac section
   - Check if decoded text resembles corresponding month name
   
   Example hypothesis:
   - Virgo section (September) should have word sounding like "september"
   - Pisces section (March) should have word sounding like "martius/marzo"

4. ZODIAC SIGN NAME TEST
   - Also look for constellation names themselves:
     * Pisces = Latin "Pisces", Italian "Pesci", Basque "Arrainak"
     * Aries = Latin "Aries", Italian "Ariete", Basque "Aharia"
     * etc.
   - Each section should have its own zodiac name + month name

5. CROSS-SECTION PATTERN ANALYSIS
   - Look for repeated structure across sections:
     * Position of month name (first word? labeled position?)
     * Position of zodiac name
     * Common "frame" words (date formula like "in the month of X")

WHY THIS IS CRITICAL:
================================================================================

Month names are a CONTROLLED TEST:
- We KNOW the expected answers (12 month names)
- We KNOW which section should contain which name
- If NO month names match ANY language → question the phonetic mapping
- If ONE language consistently matches → strong evidence for that language

This could be the "Rosetta Stone" moment if month names are found!

================================================================================

- Italian is strong because of Veneto origin hypothesis
- Hungarian because of Prague/Rudolf II connection
- Basque as the current top candidate from Track 1

Don't force matches - if nothing works, that's important data too.
