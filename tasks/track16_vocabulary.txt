================================================================================
TRACK 16: LATIN-VOYNICH VOCABULARY BUILDING
================================================================================

GOAL:
Build a comprehensive Latin-Voynich dictionary by systematically matching
the most frequent Voynich words against Latin botanical/medical vocabulary.

================================================================================
CONFIRMED PHONETIC MAP (USE THIS):
================================================================================

o→a  h→r  9→s  k→n  c→c  7→l  m→m  4→qu  1→t  8→d  a→e  e→i  2→b  y→i

Abbreviation expansions:
  -9 → -us/-is    -89 → -orum    -am → -am    -oe → -ae    -ay → -i

================================================================================
INPUT DATA:
================================================================================

1. /voynich_raw.txt - Full transcription
2. /results/latin_abbreviation_test.json - Previous matches
3. /results/zodiac_latin_analysis.json - Confirmed mappings

================================================================================
TASKS:
================================================================================

1. EXTRACT TOP 200 VOYNICH WORDS
   - Count all word frequencies in voynich_raw.txt
   - List top 200 most common words
   - Decode each using confirmed phonetic map

2. MATCH AGAINST LATIN LEXICON
   For each decoded word, search for Latin matches:
   
   A) EXACT MATCHES
      - Direct Latin word match
      
   B) STEM MATCHES  
      - Remove case endings, match stem
      - e.g., "herbam" → "herba" (stem: herb-)
      
   C) ABBREVIATION MATCHES
      - Expand 9→us/is and check
      - e.g., "rads" could be "radix"

3. CATEGORIZE MATCHES
   Group found Latin words by category:
   - BOTANICAL: plant parts, plant names
   - MEDICAL: body parts, diseases, symptoms
   - PREPARATION: cooking, mixing, dosage
   - PREPOSITIONS: in, ad, cum, de, pro, contra
   - VERBS: est, habet, valet, facit
   - ADJECTIVES: properties (calidus, frigidus)
   - NUMBERS: unus, duo, tres...

4. PARADIGM ANALYSIS
   For words that appear in multiple forms:
   - Group by likely stem
   - Map case variations
   - e.g., 4ohan/4oham/4ohae → quaren/quarem/quarei = same word?

5. BUILD DICTIONARY
   Create structured vocabulary with:
   - Voynich form(s)
   - Decoded form
   - Latin match
   - English meaning
   - Confidence score
   - Occurrence count
