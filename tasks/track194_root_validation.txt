# Task 194: Root Validation (Anatomical Check)

## Goal
Verify if `shos` (Root) and `chol` (Leaf) appear in contextually appropriate positions within the text blocks.

## Input
- `results/parsed_text.json` (Herbal Pages)
- `results/dictionary/dictionary.json`

## Process
1.  **Position Analysis:**
    - For each Herbal page, divide the text into Top (Leaves), Middle (Stalk), and Bottom (Root).
    - Count occurrences of `chol` and `shos` in each zone.
2.  **Hypothesis Check:**
    - `chol` should cluster in the Top/Middle.
    - `shos` should cluster in the Bottom.
3.  **Score:** Calculate the correlation coefficient.

## Output
- `results/anatomical_distribution.csv`: Counts per zone.
- `results/track-194-results_summary.md`: Summary.
