================================================================================
TRACK 4: ADVANCED CIPHER ANALYSIS
================================================================================

GOAL:
Test sophisticated cipher hypotheses beyond simple substitution to determine
if the Voynich text uses complex encoding methods.

================================================================================
BACKGROUND CONTEXT:
================================================================================

Simple substitution cipher has been ruled out because:
- Character frequency distribution doesn't match any known language perfectly
- No simple mapping produces readable text

But the text DOES show natural language properties:
- Follows Zipf's Law
- Has grammatical structure (PREFIX+ROOT+SUFFIX)
- Entropy matches natural languages

This suggests either:
1. Unknown natural language (not a cipher at all)
2. Complex cipher that preserves some linguistic properties
3. Combination of encoding + natural language

================================================================================
INPUT DATA AVAILABLE:
================================================================================

1. Full transcription: /voynich_raw.txt (40,701 words, 158,959 characters)
2. Character frequency analysis from analyze.py
3. Word structure analysis from word_grammar.py
4. Phonetic mapping attempts from phonetic.py

================================================================================
SPECIFIC TASKS:
================================================================================

1. POLYALPHABETIC CIPHER TESTS
   
   Test Vigenère-family ciphers:
   - Try key lengths 2-20
   - Use Index of Coincidence to detect periodicity
   - Apply Kasiski examination for repeated sequences
   - If periodicity found, attempt frequency analysis per column

2. HOMOPHONIC CIPHER TEST
   
   Check if multiple Voynich chars map to same plaintext letter:
   - Analyze characters that appear in similar contexts
   - Group characters by positional distribution
   - Test if groups could represent single letters

3. VERBOSE CIPHER ANALYSIS
   
   Test if multiple Voynich characters encode single letters:
   - Common bigrams (oh, 4o, 1c, 89) might be single letters
   - Build "super-character" vocabulary
   - Re-run frequency analysis on collapsed text

4. NULL CHARACTER HYPOTHESIS
   
   Test if some characters are meaningless fillers:
   - Identify characters with unusual distributions
   - Remove candidates and test remaining text
   - Check if removal improves language-like properties

5. ABBREVIATION SYSTEM TEST
   
   Medieval texts often used abbreviations:
   - Look for patterns resembling Latin abbreviation marks
   - Test if word-final -9 is an abbreviation marker
   - Compare with known medieval shorthand systems

6. STEGANOGRAPHIC ANALYSIS
   
   Check for hidden encoding in plain sight:
   - First letters of words/lines
   - Every nth character
   - Positional encoding (word position encodes message)

7. TOKENIZATION ANALYSIS
   
   Test if "words" are actually encoded differently:
   - Maybe spaces are part of the cipher
   - Test sliding window on continuous text
   - Check if line breaks carry meaning

================================================================================
KEY FORMULAS:
================================================================================

Index of Coincidence:
IC = Σ(ni * (ni-1)) / (N * (N-1))
where ni = frequency of character i, N = total characters

For random text: IC ≈ 1/c (where c = alphabet size)
For English: IC ≈ 0.0667
For Voynich: Calculate and compare

Kasiski Examination:
Find repeated sequences of 3+ characters
Distance between repeats suggests key length (factor analysis)
