# Track 42: Kabbalistic Cipher Analysis

## OBJECTIVE
Test whether Voynich uses Kabbalistic encoding (Gematria, Temurah, Notarikon).
Previous analysis found sacred numbers - now we need a proper REPORT.

## INPUT FILES (REQUIRED)
- `data/eva_ivtff.txt` - Source transcription
- `results/hebrew_analysis.json` - Hebrew patterns (for glyph mapping)

## KABBALISTIC SYSTEMS TO TEST

### 1. GEMATRIA (Numerical Values)
Each Hebrew letter has a value:
```
א=1, ב=2, ג=3, ד=4, ה=5, ו=6, ז=7, ח=8, ט=9, י=10
כ=20, ל=30, מ=40, נ=50, ס=60, ע=70, פ=80, צ=90
ק=100, ר=200, ש=300, ת=400
```

Map Voynich glyphs → Hebrew values based on frequency matching.

### 2. TEMURAH (Letter Substitution)
Test these cipher systems:
- **Atbash**: א↔ת, ב↔ש (first↔last)
- **Albam**: א↔ל, ב↔מ (split alphabet in half)
- **Avgad**: shift each letter by 1

### 3. NOTARIKON (Abbreviation)
- Are 3-letter words abbreviations?
- Do line initials spell something?
- Do paragraph initials encode messages?

## TASKS

### Task 1: Gematria Analysis
1. Assign Hebrew numerical values to each Voynich glyph
2. Calculate word values
3. Search for sacred numbers:
   - 18 (chai = life)
   - 26 (YHVH = God's name)
   - 72 (shem ha-meforash)
   - 137 (kabbalah)
   - 216 (gevurah)
   - 314 (Shaddai)
   - 358 (Mashiach)
   - 613 (total commandments)

### Task 2: Temurah Testing
1. Create Atbash, Albam, Avgad mappings for Voynich alphabet
2. Apply each cipher to sample words
3. Check if results are recognizable Hebrew/words

### Task 3: Notarikon Analysis
1. Collect all 3-letter words - are they abbreviations?
2. Extract initial letters of each line
3. Extract initial letters of each paragraph
4. Check for hidden messages

### Task 4: Structural Analysis
1. Count words per folio - any sacred numbers?
2. Count lines per section
3. Look for patterns at document structure level
