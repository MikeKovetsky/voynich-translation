# Track 33: Alternative Language Screen

## OBJECTIVE
If Latin fails with the derived key, systematically test other medieval language candidates.

## BACKGROUND
Latin hypothesis validation failed:
- 2.2% medieval herbal vocabulary match
- 0.9% plant label match
- Key validation only 45%

Time to consider: What if the underlying language ISN'T Latin?

## CANDIDATE LANGUAGES
Medieval languages to test (priority order):

1. **Medieval Italian** - Manuscript possibly from Northern Italy
2. **Occitan** - Southern France/Northern Italy region
3. **Catalan** - Eastern Spain/Mediterranean
4. **Old French** - Widely used in medieval Europe
5. **Middle High German** - If provenance is Central European
6. **Hebrew** - Some scholars proposed this
7. **Arabic** - Given astronomical content

## INPUT FILES
- `results/unified_key.json` - From Track 32
- `results/botanical_decoded.json` - Decoded text
- `data/eva_ivtff.txt` - Source transcription

## TASKS

### 1. Build Reference Vocabularies
For each candidate language:
- Compile top 100 common words
- Include botanical/medical terms
- Include month names, numbers
- Source from medieval texts where possible

### 2. Test Against Decoded Text
Using the unified key from Track 32:
- Calculate vocabulary match rate for each language
- Test zodiac labels against each language's month names
- Test plant labels against each language's plant names

### 3. Structural Comparison
Compare decoded text structure with each language:
- Word length distribution
- Common endings
- Word order patterns
- Letter frequency

### 4. Specific Term Test
For each language, search for:
- "Water" equivalent
- "Flower/herb" equivalent
- "Root" equivalent
- Month names
- Common prepositions

### 5. Best Candidate Analysis
For the best-matching language:
- Deep vocabulary comparison
- Phrase pattern analysis
- Attempt sample translation
- Assess plausibility

### 6. Historical Context Check
For promising candidates:
- Does the language fit the manuscript's probable origin?
- Are there known herbals in this language?
- Does the script/abbreviation style match?
