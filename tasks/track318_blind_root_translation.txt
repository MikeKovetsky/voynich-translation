# Track 318: Blind Root Translation
# Status: Ready for Execution
# Priority: Critical (Test)

## Goal
Translate the "Blind Set" (Track 314) using **only** the Root Dictionary. We will strip all suffixes and translate the core meaning. This avoids the "Grammar Hallucination" where we guessed the function of `-y`.

## Requirements
1.  **Input:** `data/blind_set_raw.txt` (The 5 text-only pages).
2.  **Script:** `research/blind_translator.py`
    -   Load `data/blind_set_raw.txt`.
    -   For each word:
        -   Strip the suffix (using Track 312 logic).
        -   Look up the **Root** in `results/dictionary/master_dictionary_v17.json` (or best available).
        -   If Root not found, output `[ROOT-?]`.
        -   If Root found, output `MEANING`.
    -   **NO Grammar Rules:** Do not reorder words. Do not insert "The" or "And". Just raw root meanings.

## Expected Output
1.  `results/blind_translation_v1.md`:
    -   The raw "Pidgin" translation of the 5 pages.
    -   Example: `[STAR] [MOVE] [ARIES] [house]`.
    -   **Evaluation:** Does this Pidgin text make sense? Or is it random words?

## Why?
This is the "Reality Check". If the roots don't make sense in sequence, our dictionary is wrong, regardless of the grammar.
