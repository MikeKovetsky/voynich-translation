PART A: HUNGARIAN TESTING
================================================================================

1. GET HUNGARIAN BOTANICAL VOCABULARY
   - Search for medieval Hungarian plant names (15th-16th century)
   - Modern Hungarian plant names:
     * Cornflower = "Búzavirág" (wheat-flower)
     * Hellebore = "Hunyor" 
     * Poppy = "Mák"
     * Cyclamen = "Ciklámen" (loan) or "Disznókenyér" (pig-bread)
     * Castor = "Ricinusfa"

2. VOWEL HARMONY TEST
   - Hungarian uses front/back vowel harmony
   - Front vowels: e, é, i, í, ö, ő, ü, ű
   - Back vowels: a, á, o, ó, u, ú
   - Check if Voynich words show vowel harmony:
     * Extract all words, map vowel-like chars (o, a, e?)
     * Test if words tend to have consistent vowel type
     * If harmony present → supports Hungarian/Turkish

3. HUNGARIAN SUFFIX MAPPING
   Hungarian cases (singular):
   - Nominative: -Ø (no ending)
   - Accusative: -t
   - Dative: -nak/-nek
   - Genitive: -é
   - Instrumental: -val/-vel
   - Superessive: -n/-on/-en/-ön
   - Inessive: -ban/-ben
   - Illative: -ba/-be
   - Elative: -ból/-ből

   Map to Voynich suffixes:
   - '9' → Nominative (-Ø)? But 37% have this ending...
   - 'am' → Could be accusative?
   - 'an' → Superessive (-n)?

4. ARTICLE PATTERN TEST
   - Hungarian definite article: "a" (before consonant), "az" (before vowel)
   - Voynich '4o' = 12.9% as prefix
   - Does '4o' behave like Hungarian article?
     * Check if '4o-' words are nouns (follow article pattern)
     * Check distribution matches article usage
