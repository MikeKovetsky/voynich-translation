# Track 44: "Cohen" Pattern Investigation

## OBJECTIVE
Track 43 found multiple Voynich words mapping to "cohen" (Hebrew: כהן = priest).
Investigate if this is meaningful - author signature, section marker, or cipher key.

## INPUT FILES
- `data/eva_ivtff.txt` - Source transcription
- `results/judeo_italian_analysis.json` - Contains cohen matches

## BACKGROUND
Found variants: qokaiin, qokain, okaiin, okain, kaiin, kain, lkaiin, ykaiin, olkaiin
All potentially map to "cohen" (priest) in Hebrew/Judeo-Italian.

In medieval Jewish texts, "Cohen" could indicate:
- Priestly family name
- Author attribution
- Section about priestly matters
- Medical authority (physicians were often Cohens)

## TASKS

### 1. Find ALL Cohen Variants
Search for patterns matching cohen:
- `*kaiin*`, `*kain*`, `*koain*`
- Any word containing `khn`, `chn`, `kn` consonant skeleton
- Build complete list with frequencies

### 2. Positional Analysis
For each cohen variant:
- Where does it appear? (line start, middle, end)
- Which folios have the most?
- Any clustering in specific sections?

### 3. Context Analysis
For each occurrence:
- What words appear BEFORE it?
- What words appear AFTER it?
- Is there a pattern? (e.g., always follows certain words)

### 4. Section Distribution
Map cohen occurrences to manuscript sections:
- Botanical (f1-f66)
- Astronomical (f67-f73)
- Biological/Nymphs (f75-f84)
- Cosmological (f85-f86)
- Pharmaceutical (f87-f102)
- Recipes (f103-f116)

### 5. Signature Hypothesis Test
If cohen is an author signature:
- Does it appear at page beginnings/endings?
- Does it appear at paragraph boundaries?
- Is there a consistent pattern?

### 6. Cross-Reference with Illustrations
On pages with cohen variants:
- What do the illustrations show?
- Any connection to priestly/religious content?
