# Task 184: Validation Run (Color Check)

## Goal
Validate the new dictionary (Task 183) by checking if the "Color Words" correctly describe the illustrations.

## Input
- `results/dictionary/dictionary.json`
- `results/parsed_text.json` (Herbal Pages)

## Process
1.  **Select Sample:** Pick 10 Herbal pages with clear "Green Leaves" and "Red Roots".
2.  **Search Text:** Look for `or` / `ok-` (Green) and `ot-` (Red) in the text.
3.  **Score Match:**
    - +1 if "Green" appears near "Leaf" (`chol`).
    - +1 if "Red" appears near "Root" (`shor`).
    - -1 if mismatched.

## Output
- `results/color_validation_report.md`: The scorecard.
- `results/track-184-results_summary.md`: Summary.
