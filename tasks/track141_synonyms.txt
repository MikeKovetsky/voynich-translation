TRACK 141: Contextual Synonym Analysis
======================================

GOAL: Consolidate the dictionary by identifying spelling variants and synonyms.

INPUT:
- `results/master_dictionary_v7_4.json`
- `data/eva_ivtff.txt`

TASK 1: Levenshtein Matching
----------------------------
- Find unknown words that are 1 edit distance away from a Known Word.
- Check if they appear in valid contexts.
- Example: `daiin` vs `daiiin`. If `daiiin` appears at start of recipes, it's a variant.

TASK 2: Slot Analysis
---------------------
- Find words that are interchangeable.
- If `daiin A qokeey` and `daiin B qokeey` exist, A and B are functionally identical (Synonyms or same category).

TASK 3: Merge Candidates
------------------------
- Create a list of words to merge into existing definitions.

OUTPUT FILES:
- `find_synonyms.py`
- `results/synonym_candidates.json`
- `results/synonym_report.md`
