# Task 220: The "Golden Page" Selection

## Goal
Find the single most readable page to showcase the translation success.

## Input
- `results/parsed_text.json`
- `results/dictionary/dictionary_v10_0.json`

## Process
1.  **Score Pages:**
    - For each page, calculate `Score = (Known Words / Total Words) * 100`.
    - Bonus points for coherent grammar structure (`qok-ed-y` sequences).
2.  **Select Winner:** The page with the highest score.
3.  **Translate:** Generate a high-quality Markdown translation of this page.

## Output
- `results/golden_page_translation.md`: The showcase.
- `results/track-220-results_summary.md`: Summary.
