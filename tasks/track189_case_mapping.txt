# Task 189: Case Mapping

## Goal
Decode the function of the confirmed prefixes (`ot-`, `ok-`, `or-`, `op-`, `ol-`) by analyzing their collocations with verbs.

## Input
- `results/parsed_text.json`
- `results/grammar_cases.md` (Contrast pairs from Task 186)
- `results/dictionary/dictionary.json`

## Process
1.  **Verb-Prefix Correlation:**
    - For each prefix, find the most common preceding verbs.
    - If `qok-ed-y` ("Mix!") is followed by `ok-[Noun]`, then `ok-` = "With".
    - If `qok-daiin` ("Take!") is followed by `ot-[Noun]`, then `ot-` = "From".
2.  **Sentence Structure Analysis:**
    - Diagram 20 sample sentences: `[Verb] + [Prefix-Noun]`.
    - Check for consistent patterns (e.g., VSO vs SVO).

## Output
- `results/case_system_v1.md`: Proposed mapping of prefixes to cases.
- `results/track-189-results_summary.md`: Summary.
