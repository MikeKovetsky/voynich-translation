# Task 192: The Zodiac-Plant Link

## Goal
Predict the identity of unknown plants mentioned in the Astro section by using their associated Zodiac signs.

## Input
- `results/parsed_text.json` (Astro Section)
- `results/dictionary/dictionary.json`
- `web_search` (for "Plants ruled by [Sign]")

## Process
1.  **Identify Zodiac Pages:**
    - f70r-f73v contain Zodiac diagrams (Aries, Taurus, Gemini, Cancer, Leo, Virgo, Libra, Scorpio, Sagittarius, Capricorn, Aquarius, Pisces).
    - Identify which page corresponds to which sign.
2.  **Extract Plant Terms:**
    - For each page, list all plant terms found in the text (e.g., `chol`, `shos`, `oteos`, `[Unknown Noun]`).
3.  **Correlate:**
    - Search: "What plants are ruled by [Zodiac Sign/Planet]?"
    - Match: If f70r is Aries (Mars) and mentions a "Sharp Plant", it might be Nettle.
4.  **Validation:**
    - Check if the plant name appears in the Herbal section.

## Output
- `results/zodiac_plants.json`: Mapping of Sign -> Potential Plants.
- `results/track-192-results_summary.md`: Summary.
