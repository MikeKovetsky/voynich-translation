TRACK 69: Produce Readable Output
=================================

GOAL: Generate ACTUALLY READABLE translated text.
Not just coverage %, but coherent sentences a human can understand.

PROBLEM:
Our current translations look like:
"the (+ noun) verb form priest/cohen fig earth"

We need output like:
"Take fig, mix with earth, give to the priest"

INPUT FILES:
- results/master_dictionary.json
- results/grammar_words.json
- data/eva_ivtff.txt

TASK 1: Grammar Rules
---------------------
Define clear grammar transformations:
- qo- = "the" → "the [NOUN]"
- -y suffix = verb marker → "[VERB]s" or "to [VERB]"
- daiin = "of/from" → "[NOUN] of [NOUN]"
- aiin = "one" → numeral
- SOV → rearrange to SVO for English

TASK 2: Recipe Template Matching
--------------------------------
Medieval recipes follow patterns:
1. INGREDIENT LIST: "X, Y, and Z"
2. PREPARATION: "Boil/Mix/Grind..."
3. APPLICATION: "Apply to..." or "Give to..."
4. PURPOSE: "For illness/condition..."

Match Voynich lines to these templates.

TASK 3: Select Best Pages
-------------------------
Choose pages with:
- Highest translation coverage
- Clear recipe/instruction structure
- Matching illustrations

Candidates: f107r, f107v, f111v (recipes)

TASK 4: Human-Readable Translation
----------------------------------
For each selected page:
- Line-by-line translation
- Apply grammar rules
- Produce ENGLISH sentences

Format:
```
FOLIO: f107r
LINE 34:
  Voynich: pairar.al.aro.lkeey.qotal.cheotai.n.dar.okaiin.otaiin.otar.opaim
  Words: [pairar=?, al=to, aro=?, lkeey=?, qotal=fig, ...]
  Translated: "To the fig... earth..."
  Readable: "Prepare fig with earth..."
```

TASK 5: Confidence Rating
-------------------------
For each sentence:
- HIGH: >70% words translated, grammar makes sense
- MEDIUM: 50-70% translated, partial sense
- LOW: <50% translated, fragmentary

TASK 6: Compile Best Results
----------------------------
Create a "translation sample" document with:
- 10-20 BEST readable sentences
- Context (which folio, what illustration)
- Confidence rating

OUTPUT FILES (REQUIRED):
- readable_output.py
- results/readable_translations.json:
  {
    "total_lines_processed": N,
    "readable_sentences": [...],
    "high_confidence": N,
    "medium_confidence": N,
    "sample_translations": [...]
  }
- results/readable_translations_report.md:
  - Method explanation
  - TOP 20 readable sentences
  - Sample page translations
  - Honest assessment of readability
