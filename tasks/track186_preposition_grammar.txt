# Task 186: Preposition Grammar

## Goal
Re-evaluate the `o-` prefixed words (`ot-`, `ok-`, `or-`, `op-`, `ol-`) as Case Markers or Prepositions, given the failure of the Color Hypothesis.

## Input
- `results/parsed_text.json`
- `results/dictionary/dictionary.json`

## Process
1.  **Context Analysis:**
    - Select 50 sentences containing these prefixes.
    - Check the word *order*.
    - Does `ot-` always appear at the start of a phrase? (Preposition).
    - Does it appear attached to the Object of a verb? (Accusative Case).
2.  **Contrast Pairs:**
    - Find pairs like `chol` (Leaf) vs `ot-chol` (From Leaf?).
    - Find `shor` (Root) vs `ol-shor` (The Root?).
3.  **Hypothesis Mapping:**
    - `ol` = Nominative/Definite ("The").
    - `ot` = Ablative/Origin ("From").
    - `or` = Dative/Benefactive ("To/For").
    - `ok` = Instrumental ("With").

## Output
- `results/grammar_cases.md`: Proposed Case System.
- `results/track-186-results_summary.md`: Summary.
