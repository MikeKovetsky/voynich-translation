# Task 188: Web Stats Dashboard

## Goal
Visualize the progress of our Dictionary and Translation coverage using a simple React/HTML dashboard.

## Input
- `results/dictionary/dictionary.json`
- `results/parsed_text.json`

## Process
1.  **Analyze Dictionary:**
    - Count Total Words vs. "Known" Words (confidence > 0.5).
    - Count Words by Category (Plant, Star, Grammar).
2.  **Analyze Text Coverage:**
    - What % of the manuscript is now readable?
    - Breakdown by Section (Herbal vs Recipes).
3.  **Generate Data:**
    - Write `web/src/data/stats.json`.
4.  **Update UI:**
    - Edit `web/src/Stats.jsx` to display these charts.

## Output
- `web/src/data/stats.json`: The data file.
- `results/track-188-results_summary.md`: Summary.
