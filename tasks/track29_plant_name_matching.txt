# Track 29: Plant Name Matching

## OBJECTIVE
Match decoded plant names from Voynich illustrations to real botanical names to validate or refute our decoding.

## BACKGROUND
We have ~130 plant illustrations, each with labels.
If decoding is correct, labels should match real plant names.

Previous identification (visual): 8 plants at >50% confidence
Now: Test if decoded labels match these identifications.

## INPUT FILES
- `results/plant_identifications.json` - Visual IDs
- `results/botanical_decoded.json` - Decoded text
- `results/botanical_word_frequency.json` - Word frequencies
- `results/master_dictionary.json` - Dictionary

## REFERENCE DATA
Plant names to compare:
1. Latin botanical names (genus/species)
2. Medieval common names
3. Apothecary names (pharmaceutical)

## TASKS

### 1. Extract Plant Labels
From each botanical folio:
- Find the label text (usually near root or top)
- Decode using phonetic key
- Record position and context

### 2. Build Reference Plant List
Create database of expected plant names:
- ~50 most common medieval medicinal plants
- Latin names
- Common medieval variants
- Abbreviated forms

Examples:
- Artemisia (mugwort)
- Rosmarinus (rosemary)
- Salvia (sage)
- Urtica (nettle)
- Cannabis (hemp)
- Papaver (poppy)

### 3. Matching Algorithm
For each decoded label:
- Exact match search
- Stem match (ignore endings)
- Phonetic similarity (Soundex/Metaphone)
- Edit distance < 2

### 4. Cross-Reference Visual IDs
For the 8 visually-identified plants:

| Folio | Visual ID | Decoded Label | Match? |
|-------|-----------|---------------|--------|
| f17r | Cornflower | ? | ? |
| f5r | Hellebore | ? | ? |
| f6r | Poppy | ? | ? |
| f2v | Cyclamen | ? | ? |
| f25v | Castor Bean | ? | ? |

### 5. Pattern Analysis
Look for plant-naming patterns:
- Do labels follow Latin naming conventions?
- Are there consistent prefixes/suffixes?
- Do related plants have similar labels?

### 6. Statistical Validation
Calculate:
- Match rate for visual IDs
- Match rate against medieval plant database
- False positive rate estimation
