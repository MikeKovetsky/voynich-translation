# Track 31: Plant Label Key Derivation

## OBJECTIVE
Use visually-identified plants to derive/validate the phonetic key through "known plaintext" analysis.

## BACKGROUND
We have 8 plants identified visually with 40-75% confidence.
If the labels ARE plant names, we can derive what mapping would make them match.

| Folio | Visual ID | Confidence | Label | Expected Latin |
|-------|-----------|------------|-------|----------------|
| f17r | Cornflower | 75% | f2o89 | Centaurea |
| f5r | Hellebore | 60% | h2o89 | Helleborus |
| f2v | Cyclamen | 50% | hoom | Cyclamen |
| f4r | Tamarisk | 50% | ho8ae19 | Tamarix |
| f6r | Poppy | 50% | foay | Papaver |
| f25v | Castor Bean | 50% | goCam | Ricinus |
| f3r | Aloe | 40% | k2cos | Aloe |
| f9r | Oak | 40% | k98eo | Quercus |

## INPUT FILES
- `results/plant_identifications.json` - Visual IDs
- `results/plant_name_matches.json` - Previous matching attempt
- `data/eva_ivtff.txt` - Source transcription

## TASKS

### 1. Verify Visual Identifications
For the 8 identified plants:
- Review the basis for each identification
- Check botanical features against illustrations
- Rank by identification confidence

### 2. Extract Clean Labels
For each plant page:
- Find the primary label (usually near illustration)
- Get exact EVA transcription
- Note any variants or alternatives

### 3. Attempt Character Derivation (Top 3 Plants)
Focus on highest-confidence identifications:

**f17r - Cornflower (75%)**
```
Label: f2o89
Expected: centaurea OR cyanus
Derive: f→c? 2→e? o→n? 8→t? 9→a?
```

**f5r - Hellebore (60%)**
```
Label: h2o89
Expected: helleborus
Derive: h→h? 2→e? o→l? 8→l? 9→e?
```

**f2v - Cyclamen (50%)**
```
Label: hoom
Expected: cyclamen
Derive: h→c? o→y? o→c? m→l?
```

### 4. Cross-Check Derivations
Compare character mappings derived from different plants:
- Do they agree?
- Where are conflicts?
- Which derivations are most consistent?

### 5. Compare with Zodiac Derivation
From Track 30, compare:
- Same character → same derived value?
- Conflicts between zodiac and plant derivations?
- Build unified derived key

### 6. Alternative Hypothesis Test
If plant names don't work, test:
- Are labels descriptions instead? ("flower", "leaf", "root")
- Are labels medicinal uses? ("for fever", "for pain")
- Are labels abbreviated?
