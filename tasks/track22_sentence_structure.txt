# Track 22: Sentence Structure Analysis

## OBJECTIVE
Identify sentence boundaries and analyze word order patterns in Voynich text to enable coherent Latin translation.

## BACKGROUND
Phase 6 achieved 99.2% Latin word match rate, but sentences are not readable. We need to understand:
1. Where do sentences begin and end?
2. What is the word order pattern (SOV vs SVO)?
3. Are there punctuation equivalents?

## INPUT FILES
- `data/eva_ivtff.txt` - EVA transcription
- `voynich_raw.txt` - Claston transcription  
- `results/botanical_decoded.json` - Decoded botanical words
- `results/phrase_patterns.json` - Known phrase patterns
- `results/transcription_mapping.json` - EVA↔Claston conversion

## TASKS

### 1. Line Analysis
- Extract all lines from botanical section (f1r-f57r)
- Count words per line
- Identify line-initial patterns (potential sentence starters)
- Identify line-final patterns (potential sentence endings)

### 2. Punctuation Search
- Look for rare characters that might be punctuation
- Check for spacing patterns
- Identify paragraph breaks
- Find repeating line-initial markers

### 3. Word Order Analysis
For decoded phrases, analyze:
- Subject position (noun stems)
- Verb position (if identifiable)
- Preposition position (8am = "de", ek = "in")
- Adjective position relative to nouns

### 4. Latin Syntax Matching
Medieval Latin typically uses:
- SOV (Subject-Object-Verb) in formal text
- Preposition + Noun in ablative
- Adjective follows noun

Test if Voynich matches these patterns.

### 5. Sentence Boundary Detection
Using the patterns found:
- Identify likely sentence boundaries
- Calculate average sentence length
- Find sentence-initial markers
- Find sentence-final markers

### 6. Sample Sentence Extraction
- Extract 20 likely complete sentences
- Decode each word
- Attempt Latin parsing
- Score coherence
