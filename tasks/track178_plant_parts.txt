# Task 178: Plant Part Decoding

## Goal
Identify the meaning of the generic "Plant Parts" (`oty`, `otol`, `okol`) by analyzing the adjectives and verbs associated with them.

## Input
- `results/herbal_taxonomy.json` (List of Plant Parts)
- `results/parsed_text.json` (Herbal Section)
- `results/root_dictionary_v3.json` (For adjective meanings)

## Process
1.  **Context Extraction:** For each "Plant Part" candidate:
    - Find all adjectives (`o-[Root]`) modifying it.
    - Find all verbs (`qok-[Root]`) acting on it.
2.  **Semantic Profiling:**
    - If modified by "Green/Red" -> likely **Leaf/Flower**.
    - If modified by "Long/White" -> likely **Root/Stalk**.
    - If verb is "Dig/Cut" -> likely **Root**.
    - If verb is "Pluck/Gather" -> likely **Fruit/Flower**.
3.  **Cluster Alignment:**
    - Do these words align with the "Noun Clusters" from Task 168?

## Output
- `results/plant_part_profiles.md`: Analysis of each term (e.g., `oty`: Modified by X, Y; Likely "Leaf").
- `results/track-178-results_summary.md`: Summary.
