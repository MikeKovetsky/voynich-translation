# Task: The Anchor Validator (Gold Standard)
# Status: Pending
# Goal: Identify "Gold Anchors" by cross-referencing Sherwood's identifications with Voynich text.

Description:
We have a mapping of 129 folios to Latin plant names (`data/external_corpora/sherwood_plant_mapping.csv`).
We have a list of phonetic candidates (`results/phonetic_candidates.csv`) linking Voynich words to Latin words.
We need to find the INTERSECTION.

If Sherwood says f8r is *Pisum*, and the text on f8r contains a word that phonetically matches *Pisum* (or *Pea*), that is a **Confirmed Anchor**.

Requirements:
1. Create `research/anchor_validator.py`.
2. Load `data/external_corpora/sherwood_plant_mapping.csv`.
3. Load `results/phonetic_candidates.csv` (The "Bridge").
4. For each Folio in Sherwood's list:
    - Get the Voynich text for that folio (using `voynich_data.py`).
    - Get the Target Latin Name (e.g., "Pisum").
    - Check if any word in the text matches a "Phonetic Candidate" for that Latin name.
    - Also check for direct substring matches (e.g., `pis` in `pisol`).
5. Output `results/gold_anchors.csv` containing:
    - Folio
    - Voynich Word
    - Latin Match
    - Confidence (1.0 if phonetic match + correct page, 0.5 if phonetic match only).
6. Generate a report `results/anchor_report.md` summarizing the hits.

Output:
- research/anchor_validator.py
- results/gold_anchors.csv
- results/anchor_report.md
