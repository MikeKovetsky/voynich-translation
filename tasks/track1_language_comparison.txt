================================================================================
TRACK 1: AGGLUTINATIVE LANGUAGE COMPARISON
================================================================================

GOAL:
Compare Voynich grammatical patterns with specific agglutinative languages
to identify the most likely source language family.

================================================================================
BACKGROUND CONTEXT:
================================================================================

From our analysis, Voynich shows clear agglutinative structure:
- WORD = PREFIX + ROOT + SUFFIX
- 6-8 grammatical cases identified
- Case suffixes: -9 (nominative, 37%), -89 (genitive plural), -am (accusative), 
  -oe (locative), -ay (genitive), -ae (instrumental), -an (ablative)
- Common prefixes: 4o- (article/determiner), 1- (verb marker), 8- (prepositional)

This matches languages like Turkish, Finnish, Hungarian, Basque, Georgian, 
Korean, Japanese, and some extinct languages.

================================================================================
INPUT DATA AVAILABLE:
================================================================================

1. Voynich transcription: /voynich_raw.txt (40,701 words)
2. Statistical analysis results from analyze.py:
   - Character frequencies (top: o=15.8%, 9=11%, a=9.1%, c=8.7%)
   - Word length avg: 3.91 chars
   - Suffix frequency distribution
3. Grammar analysis from word_grammar.py:
   - 50+ identified root morphemes
   - Prefix/suffix combinations
   - Word paradigms (roots with 5+ forms)

================================================================================
SPECIFIC TASKS:
================================================================================

1. OBTAIN LANGUAGE CORPORA
   - Download word frequency lists for: Turkish, Finnish, Hungarian, Basque,
     Georgian, Estonian, Korean (romanized)
   - Get case ending inventories for each language
   - Get typical word structure patterns

2. CASE SYSTEM COMPARISON
   - Map Voynich endings to each language's case system:
     * -9 → which case in Turkish/Finnish/etc?
     * -am → accusative? Which languages have similar marker?
     * -oe → locative? dative?
   - Score similarity (0-100) for each language

3. PREFIX ANALYSIS
   - Compare 4o- prefix with article systems (Turkish has no articles,
     Hungarian has definite article suffix, Basque has article suffix)
   - Compare 1- prefix with verb markers
   - Score each language

4. WORD LENGTH DISTRIBUTION
   - Compare Voynich avg word length (3.91) with each language
   - Compare type-token ratio (0.2434) with each language

5. N-GRAM PATTERN MATCHING
   - Generate bigram/trigram frequencies for each target language
   - Compare cosine similarity with Voynich n-grams

6. PHONETIC MAPPING TEST
   - For top 3 candidate languages, create frequency-based character mapping
   - Apply to Voynich text and check for recognizable words
   - Score by number of valid word matches
