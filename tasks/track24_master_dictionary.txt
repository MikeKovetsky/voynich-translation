# Track 24: Master Dictionary

## OBJECTIVE
Consolidate ALL confirmed and probable Voynich→Latin mappings into a comprehensive dictionary with confidence scores.

## BACKGROUND
Across Phases 1-6, we have accumulated many word mappings scattered across different result files. Need to:
1. Collect all mappings in one place
2. Assign confidence scores
3. Resolve conflicts
4. Create usable translation resource

## INPUT FILES
- `results/botanical_decoded.json` - Decoded botanical words
- `results/botanical_word_frequency.json` - Word frequencies
- `results/anchor_word_validation.json` - Confirmed anchor words
- `results/latin_verbs.json` - Verb candidates
- `results/phrase_patterns.json` - Phrase mappings
- `results/common_words_decoded.json` - Common word analysis
- `results/voynich_vocabulary.json` - Vocabulary analysis
- `results/zodiac_latin_analysis.json` - Zodiac word mappings
- `results/transcription_mapping.json` - Character mappings

## TASKS

### 1. Collect All Mappings
From each result file, extract:
- Voynich word
- Decoded form
- Latin equivalent (if known)
- Confidence score
- Source file

### 2. Merge and Deduplicate
- Combine mappings from all sources
- When same word appears multiple times, keep highest confidence
- Flag conflicting mappings for review

### 3. Confidence Scoring
Assign confidence based on:
- **1.0**: Perfect phonetic match confirmed (e.g., o4o = aqua)
- **0.9**: Exact Latin word match
- **0.8**: Latin stem match
- **0.7**: Phonetic pattern match
- **0.6**: Contextual match
- **0.5**: Frequency-based match
- **<0.5**: Speculative

### 4. Categorization
Categorize each entry:
- `noun` - Plant parts, body parts, substances
- `verb` - Actions (if identified)
- `preposition` - de, ad, in, cum, etc.
- `adjective` - Descriptions
- `number` - Quantities
- `unknown` - Unidentified

### 5. Add Metadata
For each entry include:
- Page count (how many pages it appears on)
- Total occurrences
- Common collocations (words it appears with)
- Example contexts

### 6. Build Lookup Functions
Create Python functions:
- `lookup(voynich_word)` → returns Latin + confidence
- `reverse_lookup(latin_word)` → returns Voynich forms
- `get_by_category(category)` → returns all words of type
