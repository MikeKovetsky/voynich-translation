================================================================================
TRACK 2: ILLUSTRATION-BASED PLANT IDENTIFICATION
================================================================================

GOAL:
Identify specific plants from Voynich manuscript illustrations and correlate
them with page-specific text to find plant name patterns.

================================================================================
BACKGROUND CONTEXT:
================================================================================

The Voynich Manuscript contains ~130 plant illustrations in the "herbal" 
sections (folios 1r-66v, 90r-113v). Many look like real plants but with 
unusual stylization. If we can identify specific plants, we can:

1. Match illustration labels to known plant names
2. Use plant names as "anchor words" for decipherment
3. Validate botanical reading of text

Previous researchers (Stephen Bax) claimed to identify some plants:
- f2v: possibly cotton (Gossypium)
- f4r: possibly hellebore
- f25v: possibly juniper

================================================================================
INPUT DATA AVAILABLE:
================================================================================

1. High-resolution images available from:
   - Yale Beinecke Library: https://brbl-dl.library.yale.edu/vufind/Record/3519597
   - Direct IIIF manifest for downloading
   
2. Voynich transcription by page: /voynich_raw.txt
   - Format: <page.line>text
   - Example: <1r.1>fa19s.9,hae.ay.Akam...

3. Botanical section pages: 1r-66v (herbal A), 90r-113v (herbal B)

4. Our analysis shows potential plant-related patterns:
   - '4oh-' prefix: possibly "the herb" (appears 5238 times with this prefix)
   - Words ending in '-an': possibly "root" reference
   - Words ending in '-ae': possibly "flower" reference

================================================================================
SPECIFIC TASKS:
================================================================================

1. DOWNLOAD MANUSCRIPT IMAGES
   - Download all folios from Yale Beinecke IIIF API
   - Focus on herbal sections: f1r-f66v, f90r-f113v
   - Save as high-res JPGs in /images/ folder

2. PLANT FEATURE EXTRACTION
   For each plant illustration, document:
   - Leaf shape (simple/compound, margin type, arrangement)
   - Flower structure (petal count, color, arrangement)
   - Root type (taproot, fibrous, bulb, rhizome)
   - Overall growth form (herb, shrub, tree, vine)
   - Any distinctive features

3. BOTANICAL DATABASE MATCHING
   Compare features against:
   - USDA Plants Database
   - Plants of the World Online (Kew)
   - Medieval herbals (Tacuinum Sanitatis, Dioscorides)
   - Flora Europaea (historical European plants)

4. TEXT-IMAGE CORRELATION
   For each identified plant:
   - Extract all text from that folio
   - Identify potential plant name (usually first word or labeled word)
   - Look for patterns across multiple identified plants

5. LABEL EXTRACTION
   - Identify text that appears to be labels (near roots, flowers, etc.)
   - These short texts may be plant part names or medicinal uses
   - Compile list of potential botanical vocabulary
