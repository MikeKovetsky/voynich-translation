Task: Dictionary Consolidation (v14)
Goal: Merge all recent mining results into a single authoritative Master Dictionary.
Inputs:
- dictionary/master_dictionary_v13.json (Current Master)
- results/suffix_mining.json (From Task 251)
- results/visual_validation_report.md (From Task 250 - extract confirmed words)
- results/fuzzy_merger.json (If exists, or run the logic now)

Steps:
1. Load the Master Dictionary.
2. Ingest `suffix_mining.json`.
   - For each entry, check if the word exists.
   - If yes, update "derived_meaning" or "notes".
   - If no, add it with `confidence: 0.6` (Inferred).
3. Ingest `visual_validation` confirmations.
   - Update `or` and `ol` to `confidence: 1.0` (Verified).
4. Run Fuzzy Matching (Levenshtein Distance).
   - Find all words with freq=1.
   - Compare to words with freq > 20.
   - If distance <= 1 and lengths are compatible:
     - Treat as "Spelling Variant".
     - Add to dictionary as alias -> "See [Root]".
5. Save to `dictionary/master_dictionary_v14.json`.
6. Generate `results/dictionary_v14_stats.md` showing the new coverage.
