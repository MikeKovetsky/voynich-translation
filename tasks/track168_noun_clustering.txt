# Task 168: Noun Clustering (Semantic Web)

## Goal
Identify semantic categories for "Noun" candidates by analyzing their co-occurrence with known/structural adjectives and verbs.
We know `o-` is a noun marker. We know `dy` is a particle/suffix.
We need to group rare `o-` words based on the context they appear in.

## Input
- `results/parsed_text.json` (Tokenized text with morphology)
- `results/root_dictionary_v2.json` (Current definitions)
- `results/tagged_text.txt` (POS tagged text from Task 158)

## Process
1. **Filter for Nouns:** Select words starting with `o-` or tagged as NOUN.
2. **Context Extraction:** For each noun, extract the surrounding window (±3 words).
3. **Feature Vector:** Create a vector based on co-occurring "high-confidence" roots (e.g., `daiin`, `qok`, `chol`).
4. **Clustering:** Use K-Means or DBSCAN to cluster the nouns.
   - *Hypothesis:* Ingredients will cluster together (near "mix", "drink"). Stars will cluster together (near "sky", "light").
5. **Labeling:** Assign a tentative label to the cluster based on the common context.

## Output
- `results/noun_clusters.json`: A mapping of `word` -> `cluster_id` -> `tentative_category`.
- `results/noun_clusters_report.md`: A readable summary of the clusters found.
- `results/track-168-results_summary.md`: Summary of findings.
