TRACK 56: Dictionary Conflict Analysis
======================================

GOAL: Find and remove words with CONFLICTING meanings from our dictionary.
This is a VALIDATION task - we're checking our own work for errors.

INPUT FILES:
- results/dictionary_expansion_semantic.json
- results/dictionary_expansion_freq.json
- results/dictionary_expansion_context.json
- results/hybrid_dictionary.json

TASK 1: Find Conflicting Entries
--------------------------------
For each Voynich word in our dictionaries:
- Check if it has MULTIPLE different meanings
- Example: "qokeedy" = wheat AND capricorn AND vinegar (CONFLICT!)
- Flag words with 2+ unrelated meanings

TASK 2: Categorize Conflicts
----------------------------
For each conflict, determine:
- Same semantic domain? (wheat/barley = both grains, OK)
- Different domains? (wheat/capricorn = CONFLICT)
- Grammar vs content? (verb form vs noun = CONFLICT)

TASK 3: Build Clean Dictionary
------------------------------
Create a new dictionary with:
- ONLY words with single/consistent meanings
- Remove all conflicting entries
- Keep grammar patterns separate from content words

TASK 4: Recalculate Metrics
---------------------------
With the clean dictionary:
- What is the REAL coverage?
- How many unique words can we translate?
- What's the honest translation rate?

OUTPUT FILES (REQUIRED):
- dict_conflicts.py (analysis script)
- results/dictionary_conflicts.json:
  {
    "total_entries": N,
    "conflicting_words": [...],
    "conflict_count": N,
    "clean_entries": N,
    "removed_entries": [...],
    "clean_coverage": "X%"
  }
- results/dictionary_conflicts_report.md:
  - Summary of conflicts found
  - Examples of worst offenders
  - Clean dictionary stats
  - Honest assessment of real progress
- results/clean_dictionary.json:
  - Only validated, non-conflicting entries
  - Single meaning per word
