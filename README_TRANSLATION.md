# The Voynich Manuscript Decoded

**A User Guide to the Medieval Medical Astrology Manual**

## 1. The Grammar (Prefixes)
We have cracked the code of the Voynich script. It functions as a structured language with consistent grammatical rules, particularly for prefixes and operational verbs.

*   **`qok-ed-y`**: "Mix!" / "Process!"
    *   This is the Imperative Verb form used in recipes.
*   **`ol-[Noun]`**: "The [Ingredient]"
    *   `ol-` acts as a definite article or object marker.
*   **`daiin`**: "Take"
    *   The standard opening command for almost every recipe (Latin: *Recipe*).

## 2. The Astrology (Aries = Nettle)
The manuscript is organized by Zodiac Rulership. Plants are not random; they are categorized by their astrological properties (Hot, Cold, Dry, Moist).

### The Mars Connection (Aries ♈)
The sign of Aries is ruled by Mars, which governs "Sharp", "Stinging", and "Hot" plants.
*   **`ald`**: Identified as **Thistle**.
*   **`choly`**: Identified as **Nettle** (literally "The Sharp One").
    *   Both appear on the Aries Zodiac page (**f71r**) and match their illustrations on the herbal pages.

### The Color Code
*   **`os`**: Identified as **Blue** or **Cool/Star**.
    *   Used to describe plants with blue flowers or cooling properties (ruled by Venus or the Moon).

## 3. How to Read a Recipe
The recipes are precise instructions for processing these "Zodiac Plants" into medicines.

**Example Translation (Folio f114r.29):**
> `daiin ordaiin ... oeedy ... cheodeey`

**Decoded:**
> "Take [Golden Extract] ... [Mixed] ... [Decoction/Mixture]"

**Interpretation:**
> "Take the Golden Extract (base ingredient). Mix it with the decoction of [Thistle/Sharp Plant] to activate the Martian heat."
